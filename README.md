# ЛР5, вариант 5 — Scatter-Gather DMA (QEMU EDU)

Файлы:
- `edu_dma.c` — модуль ядра;
- `edu_dma.h` — общий ioctl-интерфейс;
- `test.c` — пользовательская программа;
- `Makefile` — сборка.

## Важное ограничение

Стандартный QEMU EDU не предоставляет SG-список аппаратных дескрипторов.
Драйвер отображает несмежные страницы через `dma_map_sg()`, а затем
последовательно передаёт данные через внутренний 4-КБ DMA-буфер EDU.
Это соответствует запасному варианту из задания.

Код ориентирован на стандартный QEMU EDU `1234:11e8`, BAR0 и его DMA
регистры `0x80`, `0x88`, `0x90`, `0x98`; IRQ status/ack — `0x24`/`0x64`.
Методичка, где DMA-регистры указаны как `0x60–0x6c`, не совпадает с
документацией стандартного QEMU EDU. Проверь конфигурацию своей VM.

## Сборка

```bash
make
```

## Проверка устройства

```bash
lspci -nn | grep -i '1234:11e8'
```

QEMU должен быть запущен с устройством, например:

```bash
-device edu
```

## Запуск

```bash
sudo insmod edu_dma.ko
ls -l /dev/dmadriver

sudo ./test 4096 1
sudo ./test 8192 2
sudo ./test 16384 4

sudo rmmod edu_dma
```

Перед запуском убедись, что драйвер не конфликтует с другим драйвером,
захватившим PCI-устройство.

## Ограничения учебной версии

- Максимальный размер передачи — 16 MiB.
- DMA mask ограничена 28 битами, как у EDU по умолчанию.
- DMA через EDU идёт последовательными кусками максимум 4096 байт.
- В этой версии ещё нет `/proc/dmadriver` и замеров `memcpy`/CPU usage.
- Перед использованием на реальной системе требуется дополнительная проверка
  таймаутного пути и удаления устройства при открытом `/dev/dmadriver`.
